# **App Name**: Futsal Scoreboard Pro

## Core Features:

- Scoreboard Component: Convert HTML/CSS for three scoreboard layouts into reusable React components.
- Central Controller: Create a controller component with UI elements to manage score, time, half, and fouls.
- State Management: Implement centralized state management using React Context to sync data across scoreboards.
- Real-time Updates: Ensure all scoreboard models update instantly based on controller inputs.
- Animated Transitions: Implement animations for score changes, timer updates, and foul notifications to enhance UX.
- Timer Functionality: Provide start, pause, and reset functionality for the game timer with countdown.

## Style Guidelines:

- Primary color: Deep violet (#5228F5) to represent the energy of futsal.
- Background color: Light gray (#F0F2F5) to ensure clarity and focus on the scoreboard.
- Accent color: Orange-red (#F52850) for highlighting important events such as score changes and foul notifications.
- Font: 'Space Grotesk' (sans-serif) for a modern, techy feel, suitable for both scoreboard numbers and team names.
- Use simple, clean icons for fouls, timer controls, and other interactive elements.
- Implement subtle flip animations for score changes and smooth transitions for timer updates to enhance the visual experience.
- Arrange the three scoreboards and central controller in a clear, organized layout, ensuring easy access to all controls and clear visibility of each scoreboard.
